# Balbooa Gridbox 3.x Language Packs

Official language packs for **[Gridbox](https://www.balbooa.com/gridbox)**.

This repository contains the language files used by Balbooa Gridbox 3.x. Language packs are maintained automatically and are updated as the Gridbox extension evolves.

<br>

> **This repository is automatically maintained.**
> Language files should not be edited manually.

<br>
<br>

## 📥 Installing a Language

Language packs are **not installed directly from this GitHub repository**.

Languages are installed from inside **Balbooa Gridbox** in your Joomla administrator panel.

For step-by-step instructions, see:

**[Language Installation — Balbooa Gridbox](https://www.balbooa.com/docs/gridbox/basics/language-installation)**

<br>
<br>

## 🌏 Need Another Language?

Don't see the language you need?

[Contact Balbooa](https://www.balbooa.com/help/contacts) and tell us which language you would like to have available.

We will consider adding it to the available language packs.

<br>
<br>

## ✍️ Translation Corrections

If you notice a missing, incorrect, or outdated translation: [contact Balbooa](https://www.balbooa.com/help/contacts).
